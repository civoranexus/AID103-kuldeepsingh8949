# 🌾 CropGuard – AI Crop Disease Detection System

## 📌 Project Overview
CropGuard is an AI-based crop disease detection system developed during the CivoraX Internship Program 2025–26.  
The system uses machine learning and computer vision techniques to identify crop diseases from leaf images, helping farmers detect diseases at an early stage and reduce crop losses.

---

## 🎯 Problem Statement
Traditional crop disease detection relies on manual inspection, which is time-consuming and error-prone.  
This project aims to automate disease detection using artificial intelligence for faster and more accurate diagnosis.

---

## ⚙️ How the System Works
1. User uploads a crop leaf image  
2. Image preprocessing is applied (resizing, noise removal)  
3. Important features are extracted from the image  
4. A trained ML/DL model analyzes the image  
5. The system predicts the disease and displays results
